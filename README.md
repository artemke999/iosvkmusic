# VK Music Studio (iOS)

Нативный клиент VK Музыки на SwiftUI для iPhone (iOS 16+) в тёмном студийном стиле.

## Возможности
- Постоянная авторизация через встроенный `WKWebView` (`vk.ru`) с автоматическим обновлением веб-токена (`6287487`) по сохранённым кукам.
- Моя музыка, Рекомендации, Популярное, Плейлисты, Глобальный поиск и локальная фильтрация.
- Нативный `AVPlayer` с поддержкой фонового воспроизведения, управления с экрана блокировки и наушников (Dynamic Island / AirPods).
- Скачивание треков в память iPhone (`Documents/Downloads`, видны в приложении «Файлы»), включая демукс HLS (`.m3u8` + AES-128 → `.aac` / `.mp3`) и оффлайн-режим.

## Как собрать `.ipa` бесплатно (без Mac)
1. Создай приватный репозиторий на GitHub и залей туда эту папку:
   ```bash
   git remote add origin https://github.com/<твой_ник>/vk-music-studio-ios.git
   git push -u origin main
   ```
2. Открой вкладку **Actions** в репозитории GitHub — воркфлоу **Build iOS IPA** запустится автоматически (или нажми **Run workflow**).
3. Через ~2 минуты внизу страницы запуска появится артефакт **`VKMusicStudio-ipa`** — скачай его и распакуй `VKMusicStudio.ipa`.
4. Установи `VKMusicStudio.ipa` на iPhone через **Sideloadly**, **SideStore** или **AltStore**.
